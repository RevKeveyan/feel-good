# Google Play Data Safety

Fill Play Console → App content → Data safety.

## Does your app collect/share user data?
Yes — collects. Does not sell. Does not share with third parties for advertising (unless analytics added later — update this form).

## Data types

| Type | Collected | Shared | Purpose | Optional |
|------|-----------|--------|---------|----------|
| Email | Yes | No | Account management | No |
| Name | Yes | No | Account management | Yes |
| Photos | Yes | No | App functionality | Yes |
| User IDs | Yes | No | App functionality | No |
| App interactions | Yes (if analytics) | No | Analytics | Yes |
| Crash logs | Yes (if Sentry) | With Sentry | Analytics | Yes |
| Device or other IDs | Yes (push token) | No | App functionality | Yes |

## Security practices
- Data encrypted in transit (HTTPS / TLS)
- Users can request deletion (in-app Delete account)
